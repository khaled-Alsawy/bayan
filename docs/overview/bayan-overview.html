Bayān — System Overview

Evidence-grounded Qur'an & Tafsir research assistant
Technical summary · September 2026

Bayān answers questions about the Qur'an in Arabic or English and shows the verses and tafsir it relied on. Its core rule: no sentence reaches the reader unless it points to a real source that is displayed next to it. Language models are used for understanding and wording; code decides what counts as evidence and renders every citation.

The model picks evidence. Code writes the citation.Models return evidence IDs, never verse text or references — so a verse cannot be invented.
Every claim is checked.A validator rejects unknown IDs and drops any sentence that adds ideas absent from its sources.
Honest when evidence is thin.If nothing survives validation, the reader sees "insufficient evidence" and the sources — not a confident guess.

4Sources

  • Qur'an (Arabic) — Uthmani script, Tanzil Project
  • English translation — Rowwad Translation Center (QuranEnc)
  • Tafsir — al-Mukhtasar fi al-Tafsir (Tafsir Center for Quranic Studies), via the Quranic Universal Library
  • Each source carries a rights policy that decides display, cloud use and local-only processing.
  • English answers use Qur'an + translation only, until an approved English tafsir is available.

5Trust by design

No invented citationsModels reference evidence IDs; verse text, surah names and numbers come from the database.
Claim-level validationUnsupported sentences are removed individually; the rest of a good answer survives.
Honest fallback"Insufficient evidence" plus sources, rather than a fluent guess.
Rights-aware routingSource policy decides whether text may reach a cloud model or stays on-device.
Private providersGroq route with zero data retention and no training; local model bound to loopback.
ObservableEvery stage emits a trace event — streamed to the UI and stored per turn in Postgres.
